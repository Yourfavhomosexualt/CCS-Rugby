# CCS Rugby

The official digital rugby hub for Ceres Sekondêre Skool in Ceres, Western Cape, South Africa.

## Features
- Rugby fixtures and match schedules
- Live scores and final results
- YouTube Live match streaming
- School rugby teams and age groups
- Staff administration for updating match information

## Status
This website is currently under development.

## Important
Fixtures, scores, streaming links and school branding must be verified before publication.
