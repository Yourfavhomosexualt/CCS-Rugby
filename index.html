About This Project

The CSS Rugby Experience

CSS Rugby brings results, fixtures and livestream viewing together in one convenient place.

The aim is to make it easier for supporters to follow school rugby and celebrate the teams.

Important notice

This website is an independent website concept and is not necessarily an official school publication.
